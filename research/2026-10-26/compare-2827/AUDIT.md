## 发现并修复的问题

### 题库

- 实际请求发现：缺少课程上下文时传空 id 会得到 HTTP 400。现在使用真实课程 ID；手动测试没有课程 ID 时使用接口可接受的 0。
- 按题目所在页面区分章节、作业和考试，补上原服务使用的请求时间和页面上下文；简答等主观题映射到其文本题型。
- 兼容 #、###、===、---、分号等单条复合答案分隔；完整单选文本和简答正文保留原文，不错误拆分。
- 校验 HTTP、业务状态、最终响应域名和可匹配答案，失败仍走既有回退。
- 切换服务清空未保存密钥；节点切换仅保留当前服务密钥。保存、移除、测试要求真实用户点击。

### 课程队列

- 增加 /mooc-ans/、/mooc2-ans/、fanyav3 课程主页及课程转接链接，保留平台转接 URL；兼容参数大小写、classid、隐藏课程字段和 personid。
- 当前页没有课程时，可从平台原有课程列表接口读取；保留登录状态，检查登录失效，支持超时和取消。
- 对 knowledgeJobCount、icon_yiwanc 和目录加载状态增加识别。课程主页能进入原生章节 iframe，不能因 iframe 尚未加载就卡住。
- 页面开始扫描前检查运行租约；过期租约需抢占并再次确认后才恢复。两个浏览器标签页共享同一存储同时启动的场景，只允许一页播放。
- 过滤损坏或非法的持久化条目，刷新、切课与暂停保留队列。仅数据变化时重绘列表，避免定时刷新抢走焦点。

### 考试

- 支持原生试卷和作答实例参数，以及 answerSheet<题号> 的完整范围。
- 允许整卷预览时先进入预览读取完整试卷；禁止整卷预览时使用逐题处理。可编辑预览页参与正常答题，不再被整个跳过。
- 支持 .popBottom 中 answerDirectSubmit 与 finalSubmit 对应确认；去除嵌套容器造成的重复候选。
- 跨页面核对题干、选项及答案指纹。选项换序、答案变化、题号重复、题量冲突和分页范围不明时不交卷。
- 交卷请求之后，用户改答、关闭开关或暂停时不继续确认。一次提交只请求一次；结果未知时刷新也不再次自动提交，需核对后手动重试。
- 不把点击交卷当作提交成功；仍以平台反馈为依据。预览没有任何可回读题目时不会仅凭旧记录交卷。

### AI 聊天与界面

- 取消后旧请求的 finally 不再改变新请求的按钮状态。
- 修改接口或模型会取消在途聊天。失败、取消时保留用户新输入的草稿。
- 服务回复按纯文本显示；保留多轮上下文和长度限制。
- 修复窄屏标签拥挤，检查新入口的键盘顺序、滚动和水平溢出。

## 真实服务证据

所有探测只使用示例题、0 课程 ID 和明显无效的测试密钥，没有使用用户账号或有效服务密钥，也没有提交真实作业或考试。

- 两个原节点均有 HTTP 响应。
- HTTPS 节点在请求 id 为空时返回 HTTP 400；其他字段相同、id 为 0 时返回 HTTP 200 及业务 code:-1006（暂无答案）。
- 直接使用修正后的本地适配器生成请求，再通过真实 HTTPS 节点执行，取得 HTTP 200 和相同的业务响应。
- 这证明节点可达且此请求能进入业务处理；不能证明有效密钥授权、配额、付费题库命中或答案正确。

脱敏探测记录保存在本地 test-results 下的 abc-*-probe.json；没有把密钥、账号或私人课程数据写进报告。
