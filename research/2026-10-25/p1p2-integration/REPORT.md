## 接入范围

| 优先级 / 功能 | 已接入的流程 | 具体边界 |
| --- | --- | --- |
| P1 直播 | 识别直播容器/路由，保持原生播放器并等待直播完成标记；相邻任务完成不会完成直播；关闭管理后退出播放队列 | 不直接伪造观看时长或完成报告；未知播放器和直播服务端心跳由原生页面处理 |
| P1 签到 | 唯一可用原生按钮、去重、平台成功反馈和超时状态；活动列表显示已结束活动 | 二维码、位置、手势、设备验证在原生页面处理；结束活动不自动点击 |
| P1 讨论 | 真实讨论路由和回复编辑器、完整主题提取、AI 草稿、回读、可选发布；本次新增且正文一致的回复才确认 | 新建话题、多编辑器、未识别回复布局需原生页面核对 |
| P1 附件 / 录音 | 工作台调用原生文件选择器、开始/停止录音及已有暂存/提交控件；控件后加载会更新 | 文件由用户选取、麦克风权限由用户授权；没有上传反馈的布局不能视为已上传 |
| P1 编程 / 互评 / 分组 | CodeMirror 5/6、Ace、Monaco/文本编辑器适配；代码或评价草稿、模型回读、原生运行/暂存/提交入口 | 本轮编程模型回归使用真实页面的 CodeMirror 结构；其他模型是通用适配。评分、成员分工、专用数学输入和未识别协议仍需页面处理 |
| P1 虚拟分页 | 从明确题量或完整题号集确认范围，当前页保存反馈后翻页，逐题台账达到整份范围才允许提交 | 没有题量和完整题号集时，当前一题不能证明整份完成 |
| P1 刷新恢复 | 保存后只持久化题目/答案指纹和来源范围；刷新后页面已有答案与检查点一致才确认 | 不盲信已离开的页，也不直接从检查点覆盖答案；其他分页须重新访问并回读 |
| P2 听力 | 按顺序提取音频，MP3/WAV 或浏览器解码转换，发送 input_audio；联网模式先转写再查询资料 | 服务商必须支持音频内容；失败时不忽略音频。音频材料不进入课程播放队列，也不缓存答案 |
| P2 编程题 | 按完整题干、当前代码和语言生成代码草稿；暂停、配置变化、手动修改后不写入旧响应 | 自动生成和自动提交分别开启；整份课后作业提交仍受独立作业范围检查 |
| P2 直接 PDF | 直接打开 mooc2-resource-index.html / index.html 时启动阅读流程，复用原生页码/滚动控件 | 未知 PDF 渲染器须专用适配；读到最后一页不等于服务端已记完成 |
| P2 OCS 协议 | GET/JSON POST/表单 POST、fetch/GM、json/text 响应、题干占位符、声明式 handler；allowCode:true 支持隔离 handler/data.handler | Worker 在 opaque-origin iframe 中限时运行，只接收请求字段/响应数据。需要页面、GM、网络的任意函数不兼容；fetch 遵循 CORS，不会暗中改用 GM |
| P2 相似匹配 | 唯一高分编辑距离候选、分差门槛，数字/否定词变更拒绝 | 相似度只用于选项候选；不能代表答案正确率 |
| P2 搜题 / 投票 | 手动题干、划选文字、选项/题型/空数、结果显示；2–5 个不同模型按配置总数取得严格多数 | 平票和失败导致票数不足不填写或随机猜答；手动搜索不自动回填页面 |

“接入”表示上述明确流程已有代码和验证，不表示所有平台页面已经自动完成。P3 的其他学习平台、选课、云同步等不在本轮范围。

## 使用位置

- 目录 → 直播与活动 / 特殊作业：原生任务操作和反馈。
- 设置 → 答题：直播、签到、讨论、特殊作业、代码生成及独立作业暂存/翻页/提交开关。
- 设置 → AI / 题库：多模型投票；手动搜题中可使用划选文字；外部题库支持 OCS 配置。
- 签到、讨论生成/发布、编程自动生成/提交、课后作业暂存/翻页/提交默认关闭；互评评分、文件内容和录音仍须本人核对。
