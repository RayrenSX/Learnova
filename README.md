# Learnova v0.1.2

Learnova is a course learning companion for Chaoxing and Pintia.

[Install Learnova](https://github.com/RayrenSX/Learnova/releases/latest/download/study-helper.user.js) · [Pintia only](https://github.com/RayrenSX/Learnova/releases/latest/download/pintia-helper.user.js) · [Releases](https://github.com/RayrenSX/Learnova/releases)

当前统一版本为 **0.1.2**。两个站点的面板标题栏均显示版本号，点击版本号或用户脚本菜单中的“检查 Learnova 更新”可手动检查。启动时每六小时至多检查一次，发现新版后显示安装提示，同一新版只发送一次桌面通知。

从旧 3.x / 1.x 版本迁移：由于名称变更且版本重置，首次请手动安装，并停用旧脚本，避免同时运行。合并版与 Pintia 独立版也应二选一。后续发布递增版本后，脚本管理器通过固定的 `.meta.js` 和 `.user.js` 地址更新。

## 安装

1. 将 `学习助手完整版.user.js` 导入 Tampermonkey，关闭原独立 Pintia 及其他重复的学习通脚本。
2. 确认扩展允许用户脚本、允许访问学习通站点；刷新课程页。
3. 默认选择播放器允许的最高倍速，无法识别或不允许时 1 倍；暂停拦截、自动继续和后台播放开启，自动答题与提交关闭。首次自动播放被拦截时手动播放一次。

“拦截页面暂停请求”直接阻止页面对助手管理的媒体调用 `pause()`。播放器的视频点击、播放/暂停按钮和媒体暂停键允许手动暂停，手动暂停后须手动播放或点击“继续播放”；弹题、验证码、助手停止和切章仍可暂停。关闭开关或停止助手时恢复播放器原方法。同源 iframe 同样适用。浏览器休眠、网络中断、预先缓存的原始暂停方法无法在调用前拦截，首次后台暂停立即恢复，其他暂停仍按“暂停后自动继续”设置处理。持续播放不代表平台一定记录进度；测试使用隔离页面与临时浏览器，不代表真实课程平台已确认学习进度。

当前脚本不需要 Vue、Pinia、Ant Design 或原服务资源。油猴仅在匹配的学习通、阅读器和 Pintia 页面注入脚本，应在课程页或 Pintia 题目页查看对应助手。

## v3.2 设置页面与新增适配

一级入口为 **目录、常用、设置、记录**，设置页内再分播放、阅读、答题、AI / 题库和全部。新安装默认显示目录，首次识别目录时将旧“常用”入口切换为目录。选项卡记住上次选择，支持左右方向键和 Home/End 切换；原有业务设置保留。

- **阅读**：默认开启。按每页间隔（默认 5 秒）和页面 URL/元素声明的计时要求逐页处理 `#pagejump` 书籍、旧版 `readweb`、Swiper PPT、PDF 页面和已识别链接入口。只点击页面控件或调用现有翻页入口，不直接请求完成接口、不设置任务完成标记；末页后等平台记录。跨域 sslibrary/xuexi365 阅读框架独立翻页，顶层不越过跨域限制强行切章。页面阅读器尚未识别时提示人工处理。
- **答案缓存**：默认开启，成功填写后缓存 AI/外部题库答案，最多 1000 条，关闭逐题联网核查后，按题干、题型、选项顺序和子题结构复用。题库页可导出/清空。随机答案、图片/未解码字体答案不缓存；缓存不是正确性认证。
- **外部题库**：在“设置 → AI / 题库 → 外部题库”中粘贴完整 JSON 并保存，支持 JSON/表单 POST、GET、鉴权 headers、请求 data 模板、答案字段路径和字符串分隔符。保存后清空输入框，不自动回显鉴权内容；留空保留原值，输入 `[]` 或点击清空按钮可清空。关闭逐题联网核查后，并行查询并按配置顺序取能匹配的结果；无结果回退 AI。支持 N1 的 OCS 配置及两种占位符语法；任意 OCS handler 不运行，只识别 N1 文档中已知的成功状态/答案字段语义。示例见 `外部题库示例.json` 与 `N1题库示例.json`。
- **普通图片题**：默认开启，使用当前配置的视觉模型。读取题目和选项图片为 Base64；跨域画布受限时用油猴下载原图。下载有超时、大小和格式限制；失败不伪装成功。需接口支持图片，图片会发送给配置服务。加密字形与原图可一起发送。
- **连线、阅读理解、完形填空**：识别章节 `.dept_select`、独立作业 `.line_answer_ct .selectBox`、`.reading_answer`、`.filling_answer`，按子题顺序匹配和填写并回读。新旧布局不同，无法识别或不完整时保留人工处理。已有任意子题答案时整题保留。
- **独立作业与考试**：考试处理、填写后下一题默认关闭；开启自动答题后可填写与切题。考试交卷及确认始终由用户手动完成，整卷预览停止查题。

当前新增适配使用隔离页面验证，真实学校页面和外部题库/视觉服务需实际配置后验证；并不声称覆盖 OCS 的全部布局或全部阅读器。

## 答题

“无可用答案时随机单选 / 多选 / 判断”默认开启，须同时开启“自动答题”才运行。本地题库、外部题库和 AI 查询失败、答案未通过信心策略或无法匹配时，从页面实际可用选项中随机选择；单选和判断只选一项，多选均匀抽取至少两项的组合，可用选项不足两项时停止随机填写，禁用选项不参与。来源记为“随机选择”、信心记为 0，随机答案不缓存。是否覆盖已有答案由重查开关控制，查询期间手动改动仍保留；暂停或取消请求后不填写。不随机填写文字题或组合题。开启随机开关会重新处理本页此前失败的选择题及判断题。自动提交仍由原开关控制，开启后随机答案也可能被提交，不保证正确。

配置接口地址、模型和密钥，或导入 `题库示例.json` 格式的本地题库。本地精确匹配优先，未命中时查询自定义接口。支持单选、多选、判断、填空、简答以及富文本编辑器。未知、低信心、冲突答案不填写；查询期间用户手动修改的答案保留。

接口支持 `/v1` 或完整 `/chat/completions` 地址，返回格式为 `{"answers":["答案"],"confidence":0.95}`。信心是模型自评，不能当作正确率。在助手的 AI 接口配置内填写密钥并保存，密钥保存在本机油猴存储并绑定接口域名；保存后清空密码框，不自动回填、不写入日志或导出。加密字体题优先解析页面字体，通过字形轮廓哈希和内置映射表还原文字；未能完整映射时才使用页面字体生成图片，需要视觉模型。普通图片题仍需人工核对。

考试处理默认关闭，考试必须手动提交。章节自动提交默认关闭；历史真实 4.2 测验二次确认和提交已验证，平台显示已完成、100 分，测试结束后已关闭自动提交。原收费题库和授权绕过未接入。
