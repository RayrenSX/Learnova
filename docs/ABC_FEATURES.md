# ABC 功能接入记录

2026-10-26，在 Learnova 0.1.3 工作版本中新增四项能力：

1. ABC / N1 题库预设，独立服务密钥保存、移除与测试。ABC 支持原默认 HTTP 节点及 HTTPS 节点 2，默认选择 HTTPS；节点切换保留服务密钥，不复用 AI 密钥。
2. 考试自动交卷独立开关。记录已填写且回读一致的题目，在确认完整题量后处理“下一步”、整卷预览、交卷及对应确认。整卷预览与刷新使用同一考试、同一来源配置下的短期核对记录；题量未知、记录不完整、人工验证或入口不唯一时不自动交卷。
3. AI 聊天页，复用现有 AI 请求与密钥来源检查；多轮上下文、取消、清空、文本安全显示，会话仅保留于当前页面。
4. 多课程队列，从当前页课程链接、课程标识或手动链接添加，勾选、排序、移除、暂停、继续、重置。平台目录全部完成且任务无阻塞，稳定核对后切课。脚本存储保留队列；跨页面租约协调运行。

代码在 `src/extended-features.js`、`tools/external-bank.cjs`，由现有构建器合并；两份根目录安装文件、GitHub 合并版和 Greasy Fork 学习通版已更新。

ABC 参考来源：[ScriptCat 2827 v4.8.3](https://scriptcat.org/zh-CN/script-show-page/2827)。仅使用公开接口字段、节点与页面交互流程进行兼容实现，未把其专有脚本实现复制进安装产物。服务密钥、配额及授权由第三方负责；本次未使用有效 ABC 密钥访问真实题库，也未操作真实考试交卷。

新增浏览器用例位于 `tests/fixtures/extended-features.cjs`。模拟验证覆盖协议与响应失败、密钥节点绑定、UI 保存与节点切换、题库填答、多轮聊天与取消、考试交卷去重及关闭开关、跨预览页恢复、队列读取排序、完成后切课与另一页面占用。既有考试预览用例已按独立交卷开关更新。

自动化测试不代表所有真实课程、考试布局、第三方题库授权或 AI 服务兼容性均已验证。使用入口和配置见 README 的“课程队列、聊天和现成题库”。

后续已按八份同类脚本、OCS 固定源码和 N1 官方说明做进一步审查，修复原生路由、题库空 ID、整卷预览、确认控件及多标签页竞态，详见 [审查与验证报告](../research/2026-10-26/compare-2827/AUDIT.md)。真实 HTTPS 节点已验证请求格式与业务响应；有效密钥下的答案命中仍未验证。
