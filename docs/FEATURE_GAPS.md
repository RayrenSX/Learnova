基于 2026-10-26 下载的 ScriptCat 同类脚本及当前源码核对。296 个脚本 ID 去重后为 295 份不同源码；宣传、关键词命中与服务端命中率不等于实际验证。

尚不完整的范围：不同课程的 PDF/阅读器、互评评分与分组分工、特殊附件/录音/编程题布局，以及真实音频/视觉服务兼容性。已存在实现，但模拟测试不能代替所有真实页面验证。

智慧树、职教云、MOOC 等平台尚未作为独立适配器实现；这是扩展产品范围。签到、直播状态等待、讨论草稿、组合题、字体解码、外部题库和多模型投票已有，不列为缺失。

0.1.3 先修复图片换题的旧响应保护、完整题库配置缓存隔离及 AI 最终响应来源检查，并澄清随机兜底等当前默认策略。上述新功能未随本补丁实现。建议下一阶段先做只读待办汇总、题目导出与课件下载。
