# 资料与复习工具实现记录

日期：2026-10-26。这些工具由先前的 0.1.3 本地工作版本补齐，并随 0.1.4 发布。

## 使用入口

- 学习通工作台首页 → **资料与复习工具**：Word/Markdown 导出，选择当前已加载题目或完整试卷只读分页，选择是否保留答案与解析；无答案版同时移除本人作答。
- 同一区域显示当前页面及可访问 iframe 中平台提供的课件原文件链接；找不到链接时明确提示。
- **跨课程待办 → 读取全部课程**：读取课程、活动、全课程作业和考试列表，显示截止时间、筛选与原页面入口，可导出。部分接口失败会显示具体错误，未知状态保留“待核对”。
- **总结资料 / 生成复习卡片**：复用当前 AI 配置，可取消、保存；卡片支持翻面、上一张、下一张和 TSV 导出。
- **AI 用量**：累计请求、失败、输入/输出 token；服务未返回 usage 时记录未知，不推算费用。学习通和 Pintia 分别在各自配置存储中统计。
- **原生复制粘贴辅助**：独立开关，支持已识别的原生输入、富文本和代码模型，尊重只读状态。
- Pintia 工作台 → **导出当前题 / 导出题目集**：当前题包含完整本人代码；题目集读取已存在考试和可访问题面，保留原 Markdown、题型与选项。无已有考试、目录不完整或取消时不下载文件。

合并版另加入智慧树、智慧职教、中国大学 MOOC 的基础工作台：原生媒体播放/暂停、唯一下一课入口、题目查询后手动应用与回读、资料导出和总结。接口配置分别保存；这些基础适配不等于三平台全部课程路由和自动流程已覆盖。Greasy Fork 学习通分发版仍只匹配学习通。

## 验证范围

`tests/study-tools.cjs` 覆盖真实 OOXML 结构、图片关系、无答案版、完整分页与取消、任务状态、三平台原生模型回读及已构建合并包启动。`tests/fixtures/learning-tools.cjs` 覆盖下载按钮、总结/卡片、用量和粘贴开关撤销；剪贴板在所有原生编辑器中的真实键盘行为尚未全面实测。Pintia 新增当前题、题目集及取消/无考试回归。

真实账号课程、全部学校页面布局、真实 AI 服务、第三方题库授权和真实考试操作尚未逐项验收。源码核对和隔离通过仅证明对应协议及模拟页面，不作为所有真实平台可用的保证。既有队列、ABC/N1、聊天与考试开关见 ABC_FEATURES.md。
