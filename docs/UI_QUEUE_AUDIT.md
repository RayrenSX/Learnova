# 0.1.4 页面分区与课程队列审查

日期：2026-10-26。账号、密码、用户脚本存储、私人课程链接及浏览器截图不纳入发布文件。

## 最终行为

- 空间页导航为“课程队列 → 常用 → 设置”，不显示播放控制、媒体统计、目录、聊天、记录、作业及资料工具。
- 学习页保留目录等学习入口。课程队列与课后作业移入常用并默认折叠；空间与学习页分别记住选项卡。
- 课程读取同时校验页面类型与真实点击事件。优先读取已加载的空间课程卡片，封面与标题按课程和班级合并，保留有效名称。新读入课程不自动勾选，已有选择、顺序与完成记录保留。
- 队列优先展示状态、进度、搜索与课程列表，手动导入和重置操作收进折叠区。复选框使用独立样式，长名称换行，窄屏操作按钮换行。
- 暂停后继续未完成的当前课程。按课程 ID 修改条目，避免筛选或其他页面更新后误操作。运行时不能排序、移除、重新读取或重复开始。
- 保留多页面租约协调；切课时停止旧页扫描，导航未生效可暂停重试。带有过期签名的章节链接改走课程入口获取新会话。
- 完成判定检查阻塞任务、剩余任务点、目录加载状态、重复行与当前课程；完成标记和非零剩余任务矛盾时不推进。
- 跨域嵌入作业保留独立处理和共享停止开关，由父课程页显示控制界面；单独打开作业页仍显示自己的界面。

## 实际页面检查

通过现有已登录会话检查了个人空间、课程列表、课程主页、章节视频和作业列表：

- 空间页显示三个导航入口，没有播放控制；实际读取 8 门已加载课程，保留原有选择。
- 章节页识别 50 节目录，目录中没有课后作业，队列位于常用；实际媒体播放与助手暂停可用。
- 作业列表显示平台提供的“暂无作业”，未填写或提交作业、考试。
- 实际发现并修正空间读取等待过长、课程链接签名失效及跨域作业重复窗口。后两项补充隔离回归验证。
- 平台随后在重复进入课程时返回了其原生 500 页面；该服务器故障不作为本地逻辑已验证通过的证据。没有尝试绕过平台验证，也不承诺所有真实课程布局均已覆盖。

## 自动化与发布检查

完整学习通回归按三片运行，覆盖题型、播放、阅读、任务、作业、考试、缓存、配置、队列与页面分区；另有 Pintia 69 项、资料工具 12 项、搜索 11 项及字体、外部题库和任务元数据单元验证。新增用例见 `tests/fixtures/course-queue.cjs`。

三片结果各为 95/95，累计 285 个用例通过；最后新增的签名入口场景已在第三片重新运行通过。GitHub 发布后下载的合并安装文件也通过页面分区与队列专项 9/9。测试均为隔离页面和模拟服务，不等同于全量真实课程验证。

所有发布版本统一为 0.1.4。构建、语法、更新通道、发行范围、Greasy Fork 可读代码和大小限制检查均通过。GitHub Actions 同时执行页面分区和队列专项回归。测试结果证明列出的范围，不表示不存在未发现的问题。
