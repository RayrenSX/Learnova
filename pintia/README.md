# Learnova for Pintia

**Pintia 代码编辑、平台测试与 AI 分析工作台 · v0.1.2**

推荐安装 [Learnova 合并版](https://github.com/RayrenSX/Learnova/releases/latest/download/study-helper.user.js)，同时支持学习通与 Pintia。仅需 Pintia 时安装 [Learnova for Pintia](https://github.com/RayrenSX/Learnova/releases/latest/download/pintia-helper.user.js)。两者二选一。

从旧版迁移时，请手动安装一次并停用旧脚本。名称与版本方案发生变化，原脚本的配置不一定能由新版读取；在“设置 → AI 服务”重新保存接口、模型和密钥即可。

## 工作台

上方为代码编辑器，下方为“测试反馈 / AI 分析 / 设置”。工作台默认贴合网页，也可切换为浮窗或恢复原网页。

- 代码区支持行号、语法高亮、补全、缩进、查找、撤销重做、折行及全屏。
- 字号支持 10–28px，代码区与下方面板的比例可拖动调整并保存。
- 语言选择使用平台提供的编译器。切题后加载对应代码，清除上一题的撤销历史与分析结果。
- 编辑内容与已适配的平台编辑器同步。页面重建造成冲突时，保留工作台内的代码并提示核对。

## 使用方法

1. 打开 `pintia.cn/problem-sets/*` 的题目页，在工作台中编写代码。
2. 点击 **运行测试**，查看编译日志、实际输出与预期输出。测试输入留空时使用第一个样例；自定义输入保留原样。此步骤不需要 AI 密钥。
3. 需要分析时，先在 **设置 → AI 服务** 填写 HTTPS 的 OpenAI 兼容接口、模型和自己的 API 密钥，再点击 **AI 分析**。
4. 核对结论、错因、修改说明和修正代码，按需点击 **应用修正**。设置中可开启自动填写。
5. 应用后可 **恢复原代码**。再次编辑或切题后，不使用旧备份覆盖新的内容。

AI 分析优先复用与当前题目、代码一致的有效平台测试反馈；没有可复用的反馈时，先运行平台测试。平台没有可用的测试入口、反馈超时或代码变化时，会停止后续分析。

Pintia 模块不点击正式提交。运行测试使用平台的不计分测试入口；是否提交由用户决定。平台可能自行保存编辑器草稿。

## 结果与数据

- 自动填写默认关闭，默认信心门槛为 0.85。模型信心属于自评，仍需核对。
- 代码为空时，可在设置中使用“按题生成代码”；它不会测试空代码，也不会正式提交。
- 手动编辑、切换语言、切题或取消后，旧请求结果失效，不再填写。
- 返回格式错误、内容截断、接口失败或编辑器不可用时，保留结果供查看或提示处理，不尝试从可见的局部代码猜测完整程序。
- 题目、代码及补充反馈会发送到你配置的 AI 服务。密钥保存在用户脚本管理器配置中，绑定接口域名；更换域名需重新提供密钥。
- 学习通与 Pintia 分别保存 AI 配置。原代码备份保留在当前页面内存中，刷新后清除。

## 版本与更新

工作台标题栏显示 `v0.1.2`。点击版本号或脚本管理器的“检查 Learnova 更新”菜单可手动检查；启动时按六小时的成功检查间隔查询 GitHub。发现新版后显示“立即更新”链接，同一新版只发送一次桌面通知。

合并版与独立版分别使用自己的安装及元信息地址。更新策略与迁移说明见 [项目 README](../README.md#版本与自动更新)。

## 开发与验证

在项目根目录安装依赖后构建：

```sh
npm ci
npm ci --prefix pintia
npm run build --prefix pintia
npm run check --prefix pintia
npm test --prefix pintia
```

本目录构建独立版，根目录 `npm run build` 将同一 Pintia 源码加入合并版。根包 `package.json` 是发布版本来源，生成的正式发布文件位于根目录 `dist/`。

`0.1.2` 构建及语法检查通过，Pintia 隔离测试 **66/66** 通过。覆盖编辑器读取与同步、测试反馈、AI 分析、应用与恢复、取消、语言和题目变化、密钥隔离及窄屏布局。隔离测试不代表所有真实题目、平台布局或服务商都已验证。

当前实现读取已适配的 CodeMirror 6 状态，通过编辑器事务写入。函数题、编程题与代码补全题保留对应题型；具体控件是否可用取决于页面布局与平台状态。
