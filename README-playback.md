只安装根目录 `学习助手完整版.user.js` 或 `学习通学习助手.user.js` 中的一份，脚本按网站自动加载。停用原独立 Pintia 脚本；学习通原配置继续保留，Pintia AI 配置独立保存。当前 P1/P2 功能、测试和边界见 [接入报告](research/2026-10-25/p1p2-integration/REPORT.md)。

新增视频下方云盘图片课件的自动滚动，设置 → 阅读 → 自动阅读开启后按间隔逐段浏览；两份脚本同步修复。验证范围见 README.md 和 REAL_TEST.md。

联网核查默认关闭，可按需开启；已保存的开关状态保留。

新增 N1/OCS 题库适配，设置 → AI / 题库 → 外部题库保存密钥即可，使用 HTTPS 表单接口。说明见 N1题库接入.md。

逐题联网由程序实际执行搜索：内置 Responses 工具或独立 Tavily 服务；失败不随机猜答。关闭联网保留原答题提示词。详见 SEARCH_DIAGNOSIS.md，真实验证边界见 REAL_TEST.md。

两份用户脚本现为相同实现。最新功能和验证边界见 README.md。v3.4.0 默认采用最高允许倍速（否则 1 倍），并逐题要求 AI 联网核查；关闭联网核查后才使用本地题库/缓存直填和随机兜底。下方较早版本说明须结合这一默认策略理解。设置已改为播放、阅读、答题、题库、记录横向选项卡。

可直接安装到 Tampermonkey 的用户脚本。课程页右下角有可拖动、收起的悬浮窗口，可配置播放、自动答题、自动提交、OpenAI 兼容接口和本地题库，并查看、导出运行日志。

## 安装与使用

1. 在 Chrome / Edge 安装 Tampermonkey（篡改猴），在扩展详情中允许用户脚本。
2. 新建脚本，将 `学习通学习助手.user.js` 内容全部粘贴进去并保存。更新旧版时直接覆盖旧脚本，避免同时启用两份。
3. 登录 <https://i.chaoxing.com>，进入课程章节学习页。默认自动开始，暂停状态会保存到下次打开。
4. 窗口 → **AI 接口配置**，填写服务商接口地址、模型名和 API 密钥。点击 **保存接口设置**，再点击 **测试连接**。
5. 点击 **开始**。如果浏览器拦截自动播放，手动点击一下播放器。
6. 若之前因缺少接口配置出现查题失败，配置后点击 **重试失败题**。

脚本文件就是全部运行代码，不需要安装 Node.js 或本项目的测试依赖。

## 可配置窗口

- **开始 / 暂停**：暂停播放器并取消正在查询的答题请求。
- **继续播放**：手动请求再播放一次；浏览器权限拒绝时需要手动启动。
- **暂停后自动继续 / 后台播放**：默认开启，可分别关闭；连续暂停会逐步延长重试间隔。后台适配在暂停助手或出现验证码时撤销。
- **拦截页面暂停请求**：默认开启，直接拦截媒体的普通 `pause()` 调用。保留播放器内手动暂停、弹题、验证码及助手停止；手动暂停后点击播放或“继续播放”。关闭开关会恢复原方法。浏览器休眠、网络中断及绕过该方法的暂停不在拦截范围内。
- **重试失败题**：重新查询因网络、配置或答案格式等原因失败的题目；保留手动填写的内容。
- **查不到答案时随机单选**：默认开启；需同时开启自动答题。查询失败、低信心或答案无法匹配时随机选择一个实际可用选项，记录随机来源和 0 信心；保留已有答案，不处理其他题型。若自动提交开启，随机答案也会提交。
- **下一章**：手动点击平台的下一章入口。
- **播放与答题设置**：倍速、静音、跳过完成任务、自动切章、自动答题、自动提交。
- **AI 接口配置**：地址、模型、密钥、最低信心阈值，带连接测试。
- **本地题库**：导入/导出 JSON，题库匹配优先于 AI；导入会替换原题库。
- **运行日志**：展示答题状态、答案来源、错误原因，支持清空与导出。日志不会包含 API 密钥。
- **只刷视频**：关闭自动答题，保留自动切章。会依次处理视频/音频卡片，章节测验保留为未完成，不自动填写或提交。
- 标题栏可拖动；右上角 `−` 收起，`+` 展开。设置区独立滚动，日志在下方显示。
- 倍速随当前播放器允许的档位更新，拒绝或重置时回退 1 倍；静音按设置应用。开启后台播放后支持失焦、最小化播放；关闭后隐藏页面不新启动播放或自动切章。无关 iframe 加载不会重启现有视频。

## AI 接口

关闭联网及独立搜索后的答题使用 **Chat Completions**。内置搜索使用 **Responses web_search**，需要实际工具记录和来源；不能仅用提示词开启搜索。独立方式可配置 Tavily 搜索地址和独立密钥，答题模型保持原值：

```text
完整地址：https://你的服务商/v1/chat/completions
基础地址：https://你的服务商/v1
模型：填写服务商提供的准确模型名称
密钥：只在悬浮窗口填写，无需写进脚本
```

基础地址按方式追加 `/chat/completions` 或 `/responses`；填写完整地址会转换到对应接口。兼容本机 `http://localhost:端口/v1` 或 `http://127.0.0.1:端口/v1`；公网地址要求 HTTPS。

题干、选项发送到配置的服务商，密钥用于 Bearer 授权。油猴若提示外部域名访问权限，允许你填写的服务域名。无内置付费题库、广告接口或预设密钥；关闭逐题联网核查后，未配置 AI 时可使用本地题库。

模型需遵循提示词，返回：

```json
{"answers":["B"],"confidence":0.95}
```

联网状态由程序执行记录决定，忽略模型自行输出的 searched。搜索无结果、失败、缺少工具记录或密钥时停止填写。具体设置、测试和能力判断见 SEARCH_DIAGNOSIS.md。用户可点击“重试失败题”重新查询。

`confidence` 是模型自评，**不是经过验证的正确率**。低于阈值、格式不正确、选项无法唯一匹配时停止填写，等待人工处理。AI 可能答错，因此默认关闭自动提交。

## 自动答题与提交

支持章节测验和视频弹题中的单选、多选、判断、填空、简答。使用页面控件点击及 input/change 事件；能读取的 textarea、普通文本框、contenteditable、UEditor textarea 和同源编辑器 iframe 可用于文字题。

查询期间如果手动改了题目，脚本保留你的输入；已填写的题目不覆盖。点击暂停、关闭自动答题或 iframe 更换时，迟到的结果不写回页面。

开启 **全部匹配后自动提交** 后：

- 视频弹题填写完整且页面确认选中后，点击其提交入口；平台显示通过后才点击继续学习。
- 章节测验所有当前题目均由脚本完整填写、且没有随后被改动时，点击已知提交入口；识别到提交确认框后确认。
- 缺题、查题失败、输入未确认或控件不识别时不会提交；日志提示手动处理。
- 提交后仍等平台将任务标记完成，再自动切章。视频播完不等于平台已记入进度。

自动提交默认关闭。打开后会实际提交当前章节测验或视频弹题，请先用关闭状态检查效果。

## 本地题库格式

参考 `题库示例.json`：

```json
[
  {
    "question": "1 + 1 = ?",
    "type": "single",
    "options": ["1", "2", "3"],
    "answers": ["B"]
  }
]
```

`question` 和 `answers` 必填。`type` 可选：`single`、`multiple`、`judgment`、`blank`、`essay`、`line`、`reading`、`cloze`。组合题 answers 按子题顺序提供。`options` 可选，但**用字母答案时建议提供选项顺序**，防止同题换序。题干采用规范化后的精确匹配；题库里有冲突答案时停止填写。

单选/多选可用字母标签或完整选项文本（单个 A–Z 一律视作标签）；判断可用 `true` / `false`；填空逐空提供答案；简答提供一个文本。

## 当前限制

- 已在 Vivaldi 的真实学习通课程验证视频自动加载和播放，已修正隐藏试听音频、新版任务容器和章节导航的兼容问题。实测随后出现 `[9010]` 操作异常验证码，现已停止真实页面自动操作并恢复 1x 设置。v2.1.2 的播放调度修正通过隔离测试，完整视频任务记录与连续切章尚未实测通过；AI 服务尚未实测。
- 视频、题目和编辑器须可同源访问；跨域任务无法读取时会阻止自动切章，并记录原因。
- 加密字体先解码，不完整时通过字形画布查询视觉模型；普通图片可读取为 Base64 后识图，不能读取的图片留待人工处理。
- 考试处理、下一题和提交需各自开启开关；不处理人脸/扫码验证、不伪造时长。文档按已识别页面控件正常翻页，由平台标记进度。
- 出现平台 `[9010]` 图片验证码时暂停任务并提示人工处理，验证页解除后恢复扫描；不会自动解答验证码。
- AI 服务的额度、模型是否可用、答案准确率需要实际配置后检查。连接测试只验证协议和返回格式。

```powershell

npm run check
npm test
```
